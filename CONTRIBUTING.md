# Contributing to MyMilo Android

MyMilo Android is the Capacitor shell for the MyMilo personal AI
assistant. The app UI is plain web tech in `www/` (no build step);
Capacitor wraps it into the Android app. The `android/` project is
generated by Capacitor and is not committed.

## Prerequisites

- Node.js 20 (the version CI uses)
- JDK 17 (CI uses Temurin 17) — needed by the Gradle build once the
  Android platform is generated

## Set up and build

```bash
npm install
npx cap add android      # generates android/ (gitignored)
npx cap sync android     # also available as: npm run sync
cd android && ./gradlew assembleDebug
```

The debug APK lands at
`android/app/build/outputs/apk/debug/app-debug.apk`.

To work on the UI, edit the files in `www/` directly, then re-run
`npx cap sync android` to copy them into the Android project.

## Tests

This repository has no automated test suite yet. The check is the
build itself: if `assembleDebug` succeeds, the change compiles and
packages. Please run the local build above before opening a pull
request, and say in the PR what you verified on a device or emulator.

## CI and releases

`.github/workflows/android.yml` runs on every push to `main` (and on
manual dispatch): Node 20 + JDK 17, Capacitor sync, Gradle
`assembleDebug`. The APK is uploaded as a workflow artifact and, for
`main`, published as a GitHub release tagged `build-<run number>`
containing `app-debug.apk` for sideloading.

## Pull requests

- Branch off `main` and open a pull request back to `main`.
- Keep changes scoped; the UI, the Capacitor configuration, and the
  CI workflow are separate concerns.
- Describe what you verified (local build, device/emulator, which
  MyMilo server version you connected to).
- Update `CHANGELOG.md` under `[Unreleased]` for user-visible
  changes, and `README.md` when behaviour, install, or build steps
  change.

## Versioning

`package.json` carries the package version (currently 0.1.0).
Published releases are the CI `build-<run number>` tags; there are
no semantic-version release tags in this repository.
