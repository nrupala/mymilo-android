# MyMilo Android

The MyMilo Android app — a native shell (Capacitor) for the
[MyMilo](https://github.com/nrupala/mymilo) personal AI assistant.

**Owner:** Nrupal Akolkar · Built with Muse by Meta

## What it is

A lean mobile client that talks to cloud MyMilo (v0.31.0+) using a
device token. Offline-first: messages queue locally when the network
is down and flush when it returns; sessions sync from the server.

For the full architecture, see `docs/ANDROID-NATIVE-DESIGN.md` in the
[mymilo repo](https://github.com/nrupala/mymilo).

## Install (sideload)

1. Download `app-debug.apk` from the latest
   [release](https://github.com/nrupala/mymilo-android/releases).
2. Open it on your phone; allow "install unknown apps" if prompted.
3. First run: paste a device token.
   - Get one by signing in to MyMilo in a browser and calling
     `POST /v1/devices/register` (the token is shown once).

## Build

CI builds the APK on every push to `main` (GitHub Actions,
`.github/workflows/android.yml`): Node + JDK 17 → Capacitor sync →
Gradle `assembleDebug` → APK artifact + release.

Local build:

```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

## Layout

- `www/` — the app UI (chat, auth, offline queue, sync). No build step.
- `capacitor.config.json` — app id `org.aimlds.mymilo`.
- `android/` — generated by Capacitor in CI (not committed).
